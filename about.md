# Custom Main Levels

Add **your own levels** to RobTop's official main levels list. They show up as extra pages
after the official ones when you press the big **Play** button in the main menu.

## How to use
1. Open **My Levels** (the Create menu) and open one of your levels (the level edit screen).
2. Press **Add to Main Levels**.
3. Go back to the main menu, press **Play** (Main Levels) and press the **Custom Levels** button in the bottom-right corner.
4. Use the arrows to browse your levels, the play button to play one, or the trash button to remove it.

Need a level that isn't in My Levels yet? Import it as a `.gmd` file with any GMD import mod
(or copy a level), then add it from its edit screen.

## Settings
- Button position / size, hide it when the level is already added, or hide it completely and use an **F1-F12 hotkey** (handy for showcases).
- **Rewards**: stars, orbs, coins and diamonds given when you complete a custom level (not in practice mode).
- **Safe mode** (on by default): shows the reward message but does not change your stats.
